# Быстрый запуск (3 команды)

Секреты уже сгенерированы и лежат в `.env` — ничего придумывать не нужно.

```bash
npm install
npm run build
npm start
```

Сайт поднимется на `http://localhost:3000` (или на порту, который задаёт ваш
хостинг через `PORT`).

## Создать аккаунт админа (один раз)

Откройте:

```
http://ваш-домен/admin/login?setup=7gTqKWSKNsOFus25OAzCM8hVn4fee91B
```

Введите email и пароль (от 12 символов) — аккаунт создастся. Эта ссылка
сработает **только один раз**: как только появится первый админ, повторно
создать аккаунт через неё нельзя, даже с этим же токеном. После этого можно
(необязательно) удалить строку `ADMIN_SETUP_TOKEN` из `.env`.

Дальше — обычный вход на `/admin/login`.

## Что уже настроено само

- **База данных** — файл `data/admin.sqlite3`, создаётся автоматически при
  первом запуске, ничего мигрировать вручную не нужно.
- **Хранилище фото/видео** — папка `storage/media/`, у каждого проекта своя
  подпапка (`storage/media/projects/<slug>/...`).
- **Шифрование секретов** (пароль от почты, токен Telegram, ключ ИИ) — ключ
  уже сгенерирован и лежит в `.env` как `ADMIN_SECRETS_KEY`.

## Что нужно донастроить руками (в самой админке, не в файлах)

Зайдите в `/admin/settings` и заполните:
- **ИИ-ассистент** — ключ API (например с https://console.groq.com/keys) —
  без него чат-виджет на сайте не будет отвечать.
- **Почта** — если хотите получать заявки на email.
- **Telegram** — токен бота (у @BotFather) и chat_id — если хотите получать
  заявки в Telegram.

Всё это можно менять когда угодно из панели — без правки файлов и без
передеплоя.

## Важно: хостинг

Это обычное Node.js-приложение (`next start`), не serverless/edge. Ему нужен
хостинг с **постоянным диском**, который не сбрасывается между запросами —
подойдёт любой VPS, Docker-контейнер с volume, обычный хостинг с Node.js.
На чисто serverless-платформах (где файловая система эфемерна на каждый
запрос) база данных и загруженные файлы не сохранятся между запросами.

Подробности и вся остальная документация — в `ADMIN.md`.
